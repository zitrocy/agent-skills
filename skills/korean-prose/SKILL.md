# Korean Prose

## Purpose
독자와 매체에 맞게 한국어 기술 문장, PR 설명, UI 문구를 다듬는다. 사실, 코드, 링크, API 이름과 제품 용어는 보존한다.

## 작업 방식
1. 목적, 독자, 형식과 존댓말 수준을 확인한다. 결정에 필요한 정보가 없으면 질문한다.
2. 핵심을 먼저 쓰고 문장마다 하나의 주제를 다룬다. 긴 문장은 관계가 드러나도록 나눈다.
3. 주어, 행위자, 조건, 결과를 명확히 한다. 근거 없는 원인이나 수치를 추가하지 않는다.
4. 용어와 표기, 시제, 띄어쓰기, 존대 수준을 일관되게 맞춘다. 번역투는 의미를 해치지 않는 범위에서 자연스럽게 바꾼다.

## 매체별 기준
- 기술 문서: 맥락과 전제, 수행 단계, 결과 및 제한을 구분한다. 코드는 실행하거나 검증했다고 주장하지 않는다.
- PR: 변경 배경, 핵심 변경, 테스트 결과, 위험과 롤백을 확인된 내용만 쓴다. 모르는 테스트는 미확인이라고 표시한다.
- UI: 사용자가 해야 할 행동과 결과를 짧고 분명하게 쓴다. 오류에는 문제와 가능한 해결 방법을 담고 사용자를 탓하지 않는다. 글자 수 제한이 있으면 지킨다.

## 출력
기본적으로 다듬은 글을 제공한다. 요청 시 주요 수정 이유와 확인이 필요한 모호한 부분을 별도로 제시한다.
